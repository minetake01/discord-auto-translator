# Discord Auto Translator

[English](README.md) | [日本語](README-ja.md) | [简体中文](README-zh-CN.md) | [繁體中文](README-zh-TW.md) | [한국어](README-ko.md) | [Français](README-fr.md) | [Deutsch](README-de.md) | [Español](README-es.md) | [Português (Brasil)](README-pt-BR.md) | [Italiano](README-it.md) | [Bahasa Indonesia](README-id.md) | [ไทย](README-th.md) | [Tiếng Việt](README-vi.md)

บอท Discord ที่ช่วยให้ผู้คนที่พูดภาษาต่างกันสามารถสื่อสารกันแบบเรียลไทม์ในเซิร์ฟเวอร์ Discord เดียวกันได้ โดยที่แต่ละคนสามารถใช้ภาษาแม่ของตนเองได้อย่างราบรื่น

เมื่อเชื่อมโยงช่องของแต่ละภาษาเข้าด้วยกันเป็น **กลุ่มแปลภาษา (Translation Group)** ข้อความใดๆ ที่ส่งในช่องหนึ่งจะได้รับการแปลโดยอัตโนมัติด้วย LLM ที่รองรับมาตรฐาน OpenAI (Chat Completions API) และส่งต่อไปยังทุกช่องในกลุ่มโดยแสดง **ชื่อและรูปโปรไฟล์ของผู้ส่งดั้งเดิม** ทำให้แต่ละช่องอ่านและสนทนาได้อย่างเป็นธรรมชาติในภาษาของตนเอง

```
#chat-ja (日本語)  ⇄  #chat-en (English)  ⇄  #chat-zh (中文)
```

## 1. คู่มือสำหรับผู้ใช้และผู้ดูแลเซิร์ฟเวอร์

### คุณสมบัติหลักและประสบการณ์การใช้งาน

- **แชทได้ตามปกติอย่างเป็นธรรมชาติ**
  ไม่ต้องพิมพ์คำสั่งพิเศษหรือใส่ Prefix ใดๆ เพียงแค่พิมพ์และส่งข้อความตามปกติ ข้อความจะได้รับการแปลและส่งไปยังช่องภาษาอื่นแบบเรียลไทม์
- **คงเอกลักษณ์และโปรไฟล์ของผู้ส่งดั้งเดิม**
  ข้อความแปลจะถูกส่งผ่าน Discord Webhook โดยคงชื่อที่แสดงและรูปโปรไฟล์ของผู้ส่งต้นฉบับไว้อย่างสมบูรณ์
- **ซิงค์ข้อมูลแบบสองทางอย่างสมบูรณ์แบบเรียลไทม์**
  - **ข้อความใหม่และไฟล์แนบ**: รองรับทั้งข้อความ รูปภาพ (รวมถึงคำอธิบายภาพ / Alt text) และไฟล์แนบประเภทต่างๆ
  - **การแก้ไขและลบข้อความ**: เมื่อแก้ไขหรือลบข้อความต้นฉบับ ข้อความแปลในช่องภาษาอื่นจะอัปเดตหรือถูกลบตามทันที
  - **การตอบกลับ (Replies)**: อ้างอิงข้อความที่ตอบกลับในภาษาปลายทางพร้อมลิงก์ไปยังข้อความที่เกี่ยวข้อง (การตอบกลับจำลอง)
  - **ข้อความที่ส่งต่อ (Forwarded Messages)**: ส่งต่อเนื้อหาพร้อมปรับแต่งหัวข้อตามภาษาของช่องปลายทาง
  - **การแสดงความรู้สึก (Reactions) และการปักหมุด (Pins)**: ซิงค์การกด/ลบ Reaction อีโมจิและการปักหมุดข้อความแบบสองทาง
  - **เธรดและฟอรัม**: รองรับทั้งเธรดทั่วไป ช่องฟอรัม และช่องสื่อ พร้อมทั้งจับคู่แท็ก (Tag) อัตโนมัติ
  - **โพล (Polls)**: แปลคำถามและตัวเลือกในรูปแบบ Embed และแจ้งผลสรุปเมื่อการโหวตสิ้นสุดลง
- **ฟังก์ชัน «View Original» (ดูข้อความต้นฉบับ)**
  คลิกขวา (หรือแตะค้างบนมือถือ) ที่ข้อความแปล แล้วเลือก **«แอป» → «View Original»** เพื่อดูลิงก์ไปยังข้อความต้นฉบับและตัวอย่างข้อความดั้งเดิม (เห็นเฉพาะคุณ)
- **การจัดการลิงก์และสื่ออย่างชาญฉลาด**
  - ลิงก์และการแท็กช่อง ข้อความ หรือเธรดที่ดูแลอยู่ จะถูกแปลงเป็น ID ของภาษาปลายทางโดยอัตโนมัติ
  - URL ของเว็บไซต์ภายนอกที่มีเวอร์ชันหลายภาษาตาม `hreflang` จะถูกแทนที่ด้วย URL ภาษาปลายทางโดยอัตโนมัติ

### ขั้นตอนการนำบอทเข้าสู่เซิร์ฟเวอร์

#### 1. เชิญบอท
สร้างลิงก์เชิญใน Discord Developer Portal โดยกำหนดสิทธิ์ดังต่อไปนี้:

- **OAuth2 Scopes**: `bot`, `applications.commands`
- **สิทธิ์ของบอท (Bot Permissions)**:
  - **ทั่วไป**: `View Channels` (ดูช่อง), `Read Message History` (อ่านประวัติข้อความ)
  - **ข้อความ**: `Send Messages` (ส่งข้อความ), `Send Messages in Threads` (ส่งข้อความในเธรด)
  - **การจัดการ**: `Pin Messages` (ปักหมุดข้อความ)
  - **Webhook**: `Manage Webhooks` (จัดการเว็บฮุก)
  - **เธรด**: `Create Public Threads` (สร้างเธรดสาธารณะ), `Manage Threads` (จัดการเธรด)
  - **รีแอ็กชัน**: `Add Reactions` (เพิ่มรีแอ็กชัน)
- **ค่าตัวเลขของสิทธิ์ (Permissions Integer)**: `2252126768139328`
  - *หมายเหตุ: หากต้องการซิงค์อีโมจิจากเซิร์ฟเวอร์อื่น ให้เปิดใช้งาน `Use External Emojis` เพิ่มเติม (Permissions Integer: `2252126768401472`)*

#### 2. เปิดใช้งานสิทธิ์พิเศษ (Privileged Intent)
ตรวจสอบให้แน่ใจว่าได้เปิดใช้งาน `MESSAGE CONTENT INTENT` ในแท็บ **Bot** บน Discord Developer Portal

### การตั้งค่าช่อง (การทำงานพื้นฐาน)

#### สร้างกลุ่มแปลภาษา
พิมพ์คำสั่ง `/new-channel` ในช่องภาษาญี่ปุ่นของคุณ (เช่น `#general-ja`):

```
/new-channel language:ja
```
*หมายเหตุ: หากละเว้น `group` บอทจะใช้ชื่อช่องปัจจุบันเป็นชื่อกลุ่ม*

#### เพิ่มช่องภาษาอื่นๆ เข้ากลุ่ม
พิมพ์คำสั่ง `/join-channel` ในช่องภาษาอังกฤษ (เช่น `#general-en`):

```
/join-channel group:general language:en
```

หากต้องการเพิ่มช่องภาษาไทย (เช่น `#general-th`):

```
/join-channel group:general language:th
```

เมื่อเสร็จสิ้น `#general-ja`, `#general-en` และ `#general-th` จะเชื่อมโยงกันและการแปลอัตโนมัติจะเริ่มทำงาน

#### การออกจากกลุ่มและการลบกลุ่ม
- นำช่องออกจากกลุ่ม: `/leave-channel group:general`
- ลบกลุ่มแปลภาษาทั้งหมด: `/delete-group group:general`
- ตรวจสอบรายการกลุ่มและช่องที่เชื่อมโยงอยู่: `/list-groups`

### สรุปคำสั่งใช้งาน

#### คำสั่ง Slash สำหรับผู้ดูแล
ตามค่าเริ่มต้น คำสั่งดูแลระบบจะใช้งานได้เฉพาะผู้ใช้ที่มีสิทธิ์ **Administrator** เท่านั้น หากต้องการอนุญาตให้บทบาทอื่นใช้งาน สามารถตั้งค่าได้ที่: **การตั้งค่าเซิร์ฟเวอร์ → การผสานการทำงาน → (ชื่อบอท) → จัดการ → สิทธิ์ของคำสั่ง**

| คำสั่ง | คำอธิบาย | ตัวเลือกหลัก |
|---|---|---|
| `/new-channel` | สร้างกลุ่มแปลภาษาใหม่และลงทะเบียนช่อง | `language` (จำเป็น): รหัสภาษา BCP-47<br>`channel` (ไม่บังคับ): ช่องเป้าหมาย (ค่าเริ่มต้น: ช่องปัจจุบัน)<br>`group` (ไม่บังคับ): ชื่อกลุ่ม (ค่าเริ่มต้น: ชื่อช่อง) |
| `/join-channel` | เพิ่มช่องเข้าสู่กลุ่มแปลภาษาที่มีอยู่ | `group` (จำเป็น): ชื่อกลุ่มเป้าหมาย<br>`language` (จำเป็น): รหัสภาษา BCP-47<br>`channel` (ไม่บังคับ): ช่องเป้าหมาย (ค่าเริ่มต้น: ช่องปัจจุบัน) |
| `/leave-channel` | นำช่องออกจากกลุ่มแปลภาษา | `group` (จำเป็น): ชื่อกลุ่ม<br>`channel` (ไม่บังคับ): ช่องเป้าหมาย (ค่าเริ่มต้น: ช่องปัจจุบัน) |
| `/delete-group` | ลบกลุ่มแปลภาษาทั้งหมดอย่างสมบูรณ์ | `group` (จำเป็น): ชื่อกลุ่มที่ต้องการลบ |
| `/list-groups` | แสดงรายการกลุ่มแปลภาษาและช่องทั้งหมดในเซิร์ฟเวอร์ | ไม่มี |
| `/set-style` | กำหนดรูปแบบหรือน้ำเสียงการแปลของกลุ่ม | `group` (จำเป็น): ชื่อกลุ่ม<br>`preset` (ไม่บังคับ): รูปแบบสำเร็จรูป (ดูตารางด้านล่าง)<br>`custom` (ไม่บังคับ): คำสั่งกำหนดเองเป็นภาษาธรรมชาติ (ไม่เกิน 200 ตัวอักษร) |
| `/add-glossary` | ลงทะเบียนคำแปลเฉพาะในคลังคำศัพท์ของเซิร์ฟเวอร์ | `term` (จำเป็น): คำต้นฉบับ<br>`translation` (จำเป็น): คำแปลที่ต้องการ<br>`attribute` (ไม่บังคับ): หมวดหมู่คำ (เช่น ชื่อคน, คำสแลง)<br>`always_include` (ไม่บังคับ): แนบใน Prompt เสมอแม้ไม่พบคำตรงๆ (ค่าเริ่มต้น: `false`) |
| `/list-glossary` | แสดงรายการคลังคำศัพท์ของเซิร์ฟเวอร์ | ไม่มี |
| `/remove-glossary`| ลบคำศัพท์ที่ลงทะเบียนไว้ออกจากคลัง | `term` (จำเป็น): คำศัพท์ที่ต้องการลบ |
| `/edit-forum-tags` | แก้ไขการจับคู่แท็กสำหรับช่องฟอรัมหรือสื่อ | `group` (จำเป็น): ชื่อกลุ่ม<br>`channel` (ไม่บังคับ): ช่องฟอรัมเป้าหมาย |
| `/bot-whitelist` | จัดการรายชื่อบอทและเว็บฮุกที่อนุญาตให้แปลภาษาอัตโนมัติ | คำสั่งย่อย: `add`, `remove`, `list`<br>`source_type`: `bot` หรือ `webhook`<br>`source_id`: Bot User ID หรือ Webhook ID |

#### คำสั่งข้อความ (สมาชิกทุกคนใช้งานได้)
- **`View Original` (เมนูแอป)**
  คลิกขวาหรือแตะค้างที่ข้อความ → **«แอป» → «View Original»** เพื่อรับลิงก์และตัวอย่างข้อความต้นฉบับ

### การปรับแต่งขั้นสูง

#### 1. รูปแบบการแปล (`/set-style`)
ปรับน้ำเสียงการแปลให้เข้ากับบรรยากาศชุมชนของคุณ (เลือกได้ระหว่าง `preset` หรือ `custom` อย่างใดอย่างหนึ่ง):

| รูปแบบสำเร็จรูป | คุณลักษณะและการใช้งาน |
|---|---|
| `default` | ภาษาพูดที่เป็นธรรมชาติเหมือนเจ้าของภาษาใช้ในการแชท |
| `casual` | ภาษาพูดที่เป็นกันเองและผ่อนคลายระหว่างเพื่อนฝูง |
| `gaming` | สแลงเกมเมอร์และภาษาชุมชนเกม |
| `friendly` | น้ำเสียงที่อบอุ่น สุภาพ และเป็นมิตร |
| `business` | สุภาพ กระชับ และเป็นมืออาชีพสำหรับธุรกิจ |
| `formal` | ภาษาทางการและสุภาพอย่างเป็นระเบียบ |
| `netslang` | สแลงอินเทอร์เน็ตและภาษาเว็บบอร์ด |
| `tweet` | สั้น กระชับ ตรงประเด็น สไตล์โซเชียลมีเดีย (X / Twitter) |
| `literal` | แปลตรงตัวตามตัวอักษรเมื่อมีหลายความหมาย |

#### 2. คลังคำศัพท์ของเซิร์ฟเวอร์ (`/add-glossary`)
กำหนดคำแปลตายตัวสำหรับชื่อตัวละคร คำศัพท์เฉพาะในเกม หรือสแลงของเซิร์ฟเวอร์ (สูงสุด 50 คำต่อเซิร์ฟเวอร์):
- **หมวดหมู่ (`attribute`)**: การระบุหมวดหมู่ เช่น "ชื่อบุคคล", "ชื่อสถานที่", "คำสแลง", "คำย่อ", "คำศัพท์เฉพาะทาง" ช่วยให้ AI เข้าใจบริบทได้แม่นยำขึ้น
- **ส่งเข้า Prompt เสมอ (`always_include`)**: เมื่อตั้งเป็น `true` คำศัพท์นั้นจะถูกส่งไปพร้อมกับบริบทเสมอ แม้จะไม่ปรากฏในข้อความโดยตรง

#### 3. การจับคู่แท็กฟอรัม (`/edit-forum-tags`)
เมื่อเชื่อมโยงช่องฟอรัม คุณสามารถจับคู่แท็กระหว่างภาษาต่างๆ ได้ เมื่อมีผู้โพสต์พร้อมแท็กในภาษาหนึ่ง โพสต์ที่ถูกมิเรอร์จะได้รับแท็กที่ตรงกันโดยอัตโนมัติ

#### 4. รายชื่ออนุญาตข้อความอัตโนมัติ (`/bot-whitelist`)
ตามค่าเริ่มต้น บอทจะข้ามข้อความจากบอทและ Webhook อื่นเพื่อป้องกันลูปไม่รู้จบ คุณสามารถใช้คำสั่ง `/bot-whitelist add` เพื่ออนุญาตบอทประกาศข่าวสาร หรือฟีด RSS ให้ได้รับการแปลและมิเรอร์ได้

## 2. คู่มือสำหรับนักพัฒนาและผู้โฮสต์เอง (Self-Hosting)

### ความต้องการของระบบและสแตกเทคโนโลยี

- **ภาษา**: Go 1.24 หรือใหม่กว่า
- **ฐานข้อมูล**: SQLite (ใช้ไดรเวอร์ Go แท้ผ่าน `modernc.org/sqlite` โดยไม่ต้องพึ่ง CGO)
- **ไลบรารี Discord**: `github.com/bwmarrin/discordgo`
- **เอนจินการแปล**: OpenAI-compatible Chat Completions API (OpenAI, OpenRouter, Azure OpenAI, Local LLM ฯลฯ)
- **การคอมไพล์ข้ามแพลตฟอร์ม**: รองรับ `CGO_ENABLED=0` เพื่อสร้างไฟล์ไบนารีเดี่ยวสำหรับ Linux, Windows และ macOS ได้อย่างสะดวก

---

### ขั้นตอนการติดตั้งและรันบอท

#### 1. สร้างบอท Discord
1. ไปที่ [Discord Developer Portal](https://discord.com/developers/applications) และสร้าง Application ใหม่
2. ในแท็บ **Bot** เปิดใช้งาน `MESSAGE CONTENT INTENT` และคัดลอก Bot Token
3. ใน **OAuth2 → URL Generator** เลือกสโคป `bot` และ `applications.commands` พร้อมสิทธิ์ที่จำเป็น และเชิญบอทเข้าสู่เซิร์ฟเวอร์

#### 2. เตรียม API ที่รองรับมาตรฐาน OpenAI
เตรียม URL ของ Endpoint, API Key และ Model ID จากผู้ให้บริการ LLM ที่คุณเลือก

#### 3. กำหนดค่าตัวแปรสภาพแวดล้อม
คัดลอกไฟล์ `.env.example` เป็น `.env` และกรอกการตั้งค่า:

### สถาปัตยกรรมและหลักการออกแบบ

#### 1. ไปป์ไลน์การแปล (Translation Pipeline)
1. **การรวบรวมบริบท (Context Assembly)**: รวบรวมหัวข้อช่อง ประวัติบทสนทนาล่าสุด การอ้างอิงการตอบกลับ ข้อมูล OGP จากลิงก์ และรูปภาพที่ย่อขนาดแล้ว
2. **การแทนที่ด้วย Placeholder**: แทนที่ Mention (`<@id>`), Emoji (`<:name:id>`), ช่อง (`<#id>`), URL และบล็อกโค้ดด้วย Token เช่น `[USER:name]`, `[EMOJI:name]`, `[SITE:N]`, `[CODE]` เพื่อป้องกันข้อผิดพลาดและ Prompt Injection
3. **การจัดโครงสร้าง Prompt และ Caching**: จัดลำดับ Prompt เป็นส่วนคงที่และส่วนแปรผันเพื่อใช้ประโยชน์จาก Prefix Prompt Caching ของผู้ให้บริการ AI
4. **Structured Outputs ในคำขอเดียว**: ใช้ `response_format.type=json_schema` (`strict: true`) เพื่อรับผลลัพธ์การแปลทุกภาษาในรูปแบบ JSON ที่มีโครงสร้างแน่นอนจากการเรียก API เพียงครั้งเดียว
5. **การประมวลผลขั้นสุดท้ายและการส่งต่อ**: คืนค่า Placeholder แปลงลิงก์ Discord ภายใน แทนที่ URL ภาษาเป้าหมาย และส่งข้อความผ่าน Webhook พร้อมกัน

#### 2. ความปลอดภัยและหลักการ Fail-Closed
- **การป้องกัน Prompt Injection**: เนื้อหาผู้ใช้ทั้งหมดจะถูก Escape ในรูปแบบ XML และแยกอยู่ในแท็กบริบทเฉพาะ
- **หลักการ Fail-Closed**: หากเกินขีดจำกัดโทเค็น (`finish_reason=length`), ได้รับ JSON ไม่ถูกต้อง หรือเครือข่ายขัดข้อง บอทจะไม่ส่งข้อความที่เสียหาย แต่จะแจ้งเตือนข้อผิดพลาดในช่องต้นทางแทน

#### 3. ความน่าเชื่อถือและความสอดคล้องของข้อมูล
- **Idempotency**: ตรวจสอบ `message_links` และ `processed_events` เพื่อป้องกันการส่งข้อความซ้ำซ้อนจาก Gateway Event
- **ธุรกรรมชดเชย (Compensating Transactions)**: หากบันทึกข้อมูลลงฐานข้อมูลล้มเหลวหลังจากส่ง Webhook บอทจะลบข้อความบน Discord ทันที
- **การซิงค์แบบสองทาง**: ซิงค์การกดรีแอ็กชันและการปักหมุดข้อความไปยังทุกช่องในกลุ่มอย่างสมบูรณ์
